# Task 9.3 — Enter 恢复 session 手动验证清单

> 手动验证清单：在**真实 macOS Terminal.app**（真实 GUI）中启动 `ccsm`，
> 在 session 上按 Enter，确认 Terminal.app 弹出新窗口，且命令正确：
>
> ```
> cd '<session.cwd>' && claude --resume <session.id>
> ```
>
> 本清单需要真实 GUI（Terminal.app 焦点切换 + 新窗口弹窗），无法在沙箱
> / CI 中自动执行。请在本地 macOS 终端按步骤执行并勾选。
>
> 沙箱侧验证（dispatch 参数与 escape 单元）见同目录
> `tests/actions/resumeSession.test.ts` 与 `tests/terminal/escape.test.ts`
> （已在本任务一并跑通，详见 `.superpowers/sdd/task-9.3-report.md`）。

## 前置条件

- macOS（Terminal.app / iTerm2 / Warp 任一已装）
- Node.js >= 18，`npm install` 完成
- 已 `npm run build`，`dist/cli.js` 存在
- `~/.claude/projects/` 至少有一个 session（caller 当前有 23 个项目）

## 代码路径速查（确认预期）

- `Enter` 按键路由：`src/tui/keyActionRouter.ts` L94-107
  → 在 `focusedPane === 'sessions' && selectedSessionId` 时回调
  `onResumeSession(sess)`；在 project pane 上则只切焦点，不恢复。
- 恢复副作用：`src/tui/App.tsx` L234-241
  → `void resumeSession(session, state.terminal).catch(...)`，terminal
  取自当前 state（按 settings 切换而重建 callback）。
- 派发逻辑：`src/actions/resumeSession.ts`
  → `dispatchOpen(terminal, { cwd: session.cwd, command: 'claude --resume ' + session.id })`
  → 不预转义 cwd / command，转义由 terminal 后端负责。
- Terminal.app 后端：`src/terminal/terminal-app.ts` → `buildTerminalAppScript`
  → AppleScript `do script "cd '<cwd>' && <command>"`：
  - cwd 用 `escapeForAppleScript`（POSIX 单引号转义，仅 `'` → `'\''`）
  - command 用 `escapeForAppleScriptDoubleQuotes`（先 `\` → `\\` 再 `"` → `\"`）

## 步骤

- [ ] **Step 1：构建**

  ```bash
  npm run build
  ```

  期望：命令成功，`dist/cli.js` 存在。

- [ ] **Step 2：启动 ccsm**

  ```bash
  ./dist/cli.js
  ```

  期望：两栏 UI 渲染，session 列表非空，状态栏 OK。

- [ ] **Step 3：聚焦 session pane 并选中任一 session**

  若在 project pane 上按 Tab 或方向键切到 session pane，再用 ↑/↓
  选中一个 session。状态栏应显示当前 session id / cwd。

- [ ] **Step 4：按 Enter**

  期望：
  - Terminal.app **跳到前台**（`tell application "Terminal" to activate`）。
  - 弹出**新窗口/标签**，提示符为 `cd '<session.cwd>' && claude --resume <id>`。
  - 命令实际执行：终端显示 `claude --resume ...` 启动信息（或恢复后
    的 Claude Code 界面）。
  - `<session.cwd>` 与 `<session.id>` 都来自 UI 上看到的真实值；
    路径中即使包含空格 / 引号也应原样执行（单引号上下文内 `&` `|` `;`
    `$` 全部 inert）。

- [ ] **Step 5：边界样本（建议手测一两个）**

  - **含空格 cwd**：选一个 `~/Library/Mobile Documents/...` 之类含空格的 session，确认 `cd` 不被截断。
  - **含单引号 cwd**（少见）：若本机存在，选中后 Terminal.app 弹窗的 cd 应正确把 `'\''` 序列拼回原 cwd；若失败则为 escape bug。

- [ ] **Step 6：回归确认（务必做一次）**

  - Enter 后回到 ccsm UI，不应出现崩溃 / 卡死。
  - 再次按 Enter（或切到另一个 session 再 Enter）仍能正常弹窗。
  - 状态栏底部若显示错误信息（如 "Terminal not authorized"），按 macOS
    `系统设置 → 隐私与安全性 → 自动化` 给 Terminal.app 授权后重试。

- [ ] **Step 7：如发现问题**

  - cwd 截断 / 转义错误 → 提交修复：

    ```bash
    git commit -m "fix(terminal): correct cwd escape in resume session"
    ```

  - 命令错误（如 `--resume` 后参数缺失）→ 检视
    `src/actions/resumeSession.ts` L36-39，确认 `session.id` 来自
    `state.selectedSessionId`（不是 displayName / path）。
  - 完全不弹窗 → 检视 `state.terminal` 与 `src/terminal/<backend>.ts`
    的对应后端实现。
